# BeatGrid

> Часть портфолио: [auryxn.codes](https://auryxn.codes) — репозиторий сайта [site-admin](https://github.com/auryxn/site-admin).

> Веб-секвенсор драм-машины на Web Audio API: 7 дорожек × 16 шагов, пресеты, свинг и сохранение паттерна в ссылке.

## Что это

BeatGrid — это **секвенсор барабанов прямо в браузере**. Вы расставляете ноты по
сетке из 7 дорожек (KICK, SNARE, CLAP, HAT, OPEN, TOM, BASS) и 16 шагов, задаёте
темп и свинг — и сразу слышите получившийся бит. Ничего не нужно устанавливать:
весь звук синтезируется на лету через **Web Audio API**, без сэмплов и без внешних
зависимостей.

Паттерн можно собрать вручную, сгенерировать случайно или взять готовый пресет
(House, Hip-hop, Breakbeat, Trap). Текущее состояние (паттерн и BPM) сохраняется в
браузере и кодируется в ссылку — можно поделиться своим битом одним URL.

## Возможности

- **Сетка 7 × 16** — семь дорожек, шестнадцать шагов.
- **Синтез звука на лету** — Web Audio API, осцилляторы и шумовой буфер, без сэмплов.
- **Планировщик с точным таймингом** — look-ahead-планирование через AudioContext.
- **Пресеты** — House, Hip-hop, Breakbeat, Trap.
- **Случайный паттерн** и **очистка** одним кликом.
- **BPM 60–180** и **свинг 0–60%**.
- **Mute** любой дорожки кликом по её названию.
- **Подсветка текущего шага** во время проигрывания.
- **Сохранение** паттерна в `localStorage` и **шаринг ссылкой** (`#b=…`).
- **Управление с клавиатуры** — пробел запускает и останавливает.

## Управление

- **Пробел** — старт / стоп.
- **Клик по клетке** — включить / выключить шаг (при клике на выключенном шаге
  звук проигрывается сразу для превью).
- **Клик по названию дорожки** — mute / unmute.
- **BPM / Свинг** — слайдеры в панели сверху.
- **Пресет…** — выбрать готовый паттерн.
- **🎲 Случайно** / **Очистить** — сгенерировать или обнулить паттерн.
- **🔗 Ссылка** — скопировать ссылку на текущий паттерн.

Ссылка-шаринг кодирует BPM и паттерн в хэш (`#b=…`): открыв её, получатель увидит
ровно тот же бит. Если хэша нет — подхватывается последний паттерн из браузера.

## Стек

- **Vite** — сборка и dev-сервер.
- **Vanilla JS** (ES-модули) — без фреймворков.
- **Web Audio API** — синтез и планировщик.
- **CSS** — тёмная тема, без препроцессоров.

## Запуск

```bash
npm install
npm run dev        # dev-сервер с HMR
npm run build      # прод-сборка в dist/
npm run preview    # локальный просмотр собранной версии
```
